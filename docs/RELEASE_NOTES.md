# Host2VMRelay v0.9.2

修复仓库迁移后软件更新地址未同步的问题，并细化 CI 检查范围。此版本同时包含 v0.9.1 的虚拟机健康探测修复。

## 更新内容

- 更新 API、公开下载回退和界面项目链接统一使用 Aegyce/host2vm-relay，发布前自动核对实际仓库地址。
- 网络测试变更不再触发五档 DPI 验收；纯更新逻辑保留应用及发布包自检，跳过 SSH/TUN 回归。共享构建、工作流和未知变更仍执行完整检查。
- SSH 与 UDP 探测等待时间从 250 毫秒调整为 5 秒；Rust SSH 内核也采用 5 秒上限，控制管道另留 1 秒响应传递余量。
- 后台探测每秒执行一次，健康状态有效期调整为 8 秒，覆盖探测等待、轮询与调度时间。
- 明确关闭的通道仍立即失效；健康状态确定后，Clash 动态同步继续每 200 毫秒执行。
- SSH 探测失败记录具体原因，便于区分响应超时、转发内核退出和远端错误。

## 验证与限制

旧版可能因安装包地址校验不匹配而无法在软件内更新，请从本版本 Release 手动下载安装包。升级后恢复正常的软件内更新。

新增真实 OpenSSH 的 4 秒延迟成功、超过 5 秒超时回归，以及 UDP 延迟、探测等待期间健康保持和显式断开立即失效测试。

此修复处理过紧的健康检查预算，不能保证解决 aTrust 或实际网络中断。既有连接在真实断网后仍需重连。升级并重启程序后生效，无需重新生成 Clash 扩展脚本。
